# Соберемся

Архитектурный репозиторий веб-приложения «Соберемся» для организации совместных онлайн- и офлайн-активностей.

Архитектурный репозиторий - средство управления архитектурной документацией, где хранится вся информация о структуре, стандартах и правилах системы.

Составлен на основе шаблона [project-doc](https://github.com/qasmark/project-doc).

## Структура

- **1. Исходные сведения** - введение, словарь, архитектурные факторы
- **ADR** - записи архитектурных решений. Именование: `ГГГГ-ММ.ДД - Название решения.md`
- **2. Технический проект** - диаграммы C4
- **3. Технические процессы** - CI/CD, ведение репозитория, соглашения
