
**Дата:** 15 ноября 2026 г.

**Статус:** Принято

**Контекст:** 

Проект является исключительно веб-приложением с приоритетом мобильных устройств (LIM01, PLT01). Требуется интерактивный интерфейс (каталог с фильтрами, формы создания активностей, чат, уведомления в реальном времени) со временем отклика не более 1 секунды

**Рассмотренные варианты:**

1. **React(vite):** Популярная и быстро развивающаяся библиотека для создания пользовательских интерфейсов
2. **Vue.js:** Прогрессивный фреймворк с легким входом и гибкостью
3. **TS / HTML / CSS:** Быстро работает, но сложно поддерживать при росте проекта.

**Решение:**

Выбран React(vite) + TypeScript

**Обоснование:**

- **Знакомость со стеком технологий**
- **Стек технологий:** React и TypeScript явно выбраны ограничениями проекта (LIM07)
- **Компонентный подход:** Позволяет создавать переиспользуемые компоненты, что ускоряет разработку
- **Производительность:** Виртуальный DOM обеспечивает быструю перерисовку чата и списка уведомлений, имеет поддержку для webscoket'a
- **Надежность:** Использование TypeScript снизит количество багов в рантайме благодаря строгой типизации
- **Мощное сообщество:** Огромное количество библиотек и ресурсов


**Последствия:**

- Приложение будет реализовано как Single Page Application.
- Необходима настройка сборщика Vite и строгости линтера
- Тексты интерфейса выносятся в файлы локализации (L10N02)
